- Español, directo y conciso (skill estilo-respuesta). Código antes que texto. Actuar con defaults razonables y decirlo; preguntar solo lo que es realmente suyo.
- Si algo falla, decir el error claro; no maquillar resultados. Decir también qué quedó sin verificar (p. ej. licencias).
- **NO sin preguntar:** publicar, gastar créditos, subir archivos a servicios externos (incluido Drive), usar música comercial.
- Ángel puede pedir cambios sobre un borrador renderizado: iterar rápido, enviar el vídeo con SendUserFile.
- «Todos estos consejos debes recordarlos para TODOS los vídeos»: aplicar esta memoria en cada edición nueva.
**Why:** velocidad → calidad → seguridad (skill como-trabajar-conmigo).
